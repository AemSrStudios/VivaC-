## 🎨 VivaC#

VivaC# is a free, modern editing application built with **C#**, **WPF**, and **.NET 8**.

The goal is to create a powerful desktop editor that is easy to use while remaining completely free.

## ✨ Features

- 🖼️ Image editing
- ✂️ Crop, resize, and rotate
- 🎨 Drawing tools
- 📝 Text layers
- 🔲 Layers
- ↩️ Undo / Redo
- 🔍 Zoom
- 🌈 Filters
- 🎚️ Image adjustments
- 💾 Save and export
- 📂 Import images
- 🖱️ Drag and drop
- ⌨️ Keyboard shortcuts
- 🖥️ Modern interface

## 💰 Free

VivaC# is intended to remain **free to use**.

There will be **no paid version required for the core editor**.

## 🛠️ Built With

- C#
- .NET 8
- WPF
- XAML
- Visual Studio

## 🚧 Development Status

VivaC# is currently in **early development**.

Features may change as development continues.
